# Recon: разделы Reg Organizer 9.94 и их место в RegKeeper

Источники: [M] - `MODLOG.md` (наблюдение за файлами, ключами и форматами установленного оригинала),
[S] - список инструментов на сайте производителя (chemtable.ru/reg-organizer.htm, 9.95),
[R] - отзывы пользователей (`replica/feedback.md`). Код, ресурсы и строки оригинала не использовались.
Функции по пунктам и статус клона - в `replica/features.csv`; сценарии проверки - в `replica/test-plan.md`.

## Деинсталлятор
- Оригинал: список установленных программ, штатное удаление, затем поиск остатков в папках и реестре [S];
  закрывает процессы программы перед удалением (`CloseApplication.dll`) [M]; список исключений хвостов, защищающий
  антивирусы (`AppUninstIgnore`, элементы «ключ» и «папка») [M]; журнал удалённых (`DeletedApps\Apps.txt`) [M].
  Хвалят полноту и удаление «неудаляемых» программ [R F9]; жалуются на снесённую систему после «полной
  деинсталляции» [R F1].
- RegKeeper: таблица программ (название, издатель, версия, размер, дата, для кого), поиск, кнопки «Удалить»,
  «Тихое удаление», «Принудительно», «Убрать запись», «Папка», «Ключ в редакторе», «Экспорт». После удаления -
  окно хвостов с галочками. Ключи уходят в Центр отмены, папки в корзину, защищённый список не предлагается.
- Состояния: загрузка списка (окно заблокировано), пустой поиск, деинсталлятор не найден (предлагается
  принудительное удаление), хвостов нет.

## Приложения Windows
- Оригинал: отдельная библиотека для Store-приложений (`WinRTApps.dll`) [M].
- RegKeeper: приложения текущего пользователя, фреймворки и системные пакеты скрыты (флажок «Показать
  системные»), «Удалить», «Папка», «Обновить». Удаление вызывает PowerShell с именем пакета аргументом, без
  подстановки в текст скрипта.
- Состояния: загрузка, пакет не удаляется (ошибка показывается), системный пакет - кнопка недоступна.

## Автозагрузка
- Оригинал: менеджер автозагрузки «отключить или отложить» [S]; служба слежения за новыми записями
  (`StartupCheckingService.exe`) [M]; свой файл состояния (`StartupItems.bin`) [M]. Жалобы: отложенный запуск
  нельзя снять, глюки при удалении [R F4].
- RegKeeper: одна таблица (Run, RunOnce, папки, задачи, службы; фильтры «Службы», «Задачи»), «Вкл / выкл»
  через штатный `StartupApproved`, «Отложить» (задача планировщика с задержкой), «Удалить», «Добавить»,
  «Папка файла», «Перейти к записи». Статус «файл не найден». Слежение - отдельный `RegKeeper.Watcher.exe`.
- Состояния: RunOnce нельзя выключить (только удалить), служба Microsoft не показывается, нет прав на HKLM.

## Очистка диска
- Оригинал: временные файлы, устаревшие обновления, предыдущие версии Windows, приватные данные браузеров и
  Windows [S]; база `winapp2.ini` и игнор-лист (`CleanupIgnore`) [M]; галочки пунктов в `CleanupParts.xml` [M].
  Жалобы: каждый день тот же мусор, находит мало, удалил нужное [R F7, F1].
- RegKeeper: встроенные пункты Windows и правила winapp2 только для найденных программ, «Анализ», «Очистить»,
  «Подробно» (файлы правила с галочками), «Исключения», «Обновить winapp2.ini». Колонка «Предупреждение»,
  после очистки - «Освобождено» и число пропущенных. Windows.old и очистки хранилища компонентов нет.
- Состояния: база не загружена (подсказка в строке состояния), нечего удалять, файлы заняты.

## Чистка реестра
- Оригинал: проверки ссылок на удалённые файлы, игнор-лист с типами «по тексту» и «по ключу»
  (`IgnoreRegCleaner`) [M]. Жалобы: ломает систему, непрозрачные числа, сбрасывает «Стандартное приложение»
  [R F1, F6, F5].
- RegKeeper: проверки Uninstall, App Paths, SharedDLLs, MUICache, Run, Installer\Folders, «Открыть с помощью»,
  брандмауэр, CLSID, TypeLib; колонка «Проблема»; «Исправить» только отмеченное через Центр отмены;
  «Игнорировать», список исключений, «Открыть» в редакторе. UserChoice и представления папок не проверяются.
- Состояния: идёт сканирование, ничего не найдено, ключ защищён (в отчёте «не удалено»).

## Редактор реестра
- Оригинал: экспорт, импорт, копирование значений [S]; редактор .reg-файлов и сборка из веток [S];
  предпросмотр .reg перед импортом [S]; избранные и последние ключи (`ExploredKeysEx`) [M]. Хвалят как замену
  regedit [R F14]; экспорт ключа подвесил систему [R F17].
- RegKeeper: дерево с ленивой загрузкой, адресная строка, «Из буфера», «Копировать путь»; разделы: создать,
  переименовать, копировать, удалить; значения всех типов; экспорт в фоне, импорт с предпросмотром по каждой
  операции; избранное. Все изменения через Центр отмены. Отдельного редактора .reg-файлов нет.
- Состояния: нет доступа к разделу, неверное значение (повтор ввода), раздел уже существует.

## Поиск и замена
- Оригинал: поиск по ключам и значениям и замена «как в текстовом редакторе» [S].
- RegKeeper: шаблон, корни поиска, где искать (разделы, имена, данные), учёт регистра, целое слово, regex;
  остановка; «Заменить», «Удалить» отмеченное через Центр отмены; «Открыть» в редакторе.
- Состояния: идёт поиск (кнопка остановки), ничего не найдено, неверный regex.

## Снимки и трассы
- Оригинал: слежение за изменениями реестра [S]; «отслеживание изменений в реестре и файловой системе»
  при установке [R F9].
- RegKeeper: «Снимок» реестра и файлов, «Сравнить» два снимка, «Трасса» установки (снимок, запуск
  инсталлятора, снимок, diff), откат трассы с галочками; список снимков и трасс с удалением.
- Состояния: снимок идёт (~40 с на полной системе), изменений нет, изменённые файлы не восстанавливаются
  (показывается списком).

## Твики
- Оригинал: каталог штатных и недокументированных настроек [S]; формат: ключ, значение, тип, состояния,
  флаги выхода и версии ОС [M].
- RegKeeper: свой каталог из 43 твиков в 10 категориях, галочка = текущее состояние, «Применить» одной
  транзакцией, «Сбросить отметки», «Ключ в редакторе», колонка «Нужно» (Проводник, выход, перезагрузка).
- Состояния: твик для HKLM без прав, после применения - вопрос о перезапуске.

## Сжатие реестра
- Оригинал: дефрагментация реестра. Жалобы: не загрузилась система, пропали значки трея, не открывается
  Office [R F2].
- RegKeeper: «Анализ» (сжатые копии во временную папку, размер до и после), «Сжать» (точка восстановления,
  бэкап, замена при перезагрузке), «Папка сжатия». SAM, SECURITY, BCD не трогаются.
- Состояния: нет прав администратора (размер «нет доступа», сжатие недоступно), выигрыша нет.

## Центр отмены
- Оригинал: файл на операцию (`UndoChangesCenter\*.ucc`) и индекс [M]. Ценят откат [R F16].
- RegKeeper: список операций с датой и составом, «Отменить», «Удалить», «Удалить старые», «Открыть .reg».
  Откат повторно не применяется: запись удаляется после успешного отката.
- Состояния: пусто, запись повреждена (пропускается в списке).

## Настройки
- Оригинал: настройки в `HKCU\Software\<производитель>\Reg Organizer` [M]; пункт контекстного меню
  (`ShellContextMenu_4.dll`) [M]; языки интерфейса (папка `Languages`) [M]. Жалобы: галочки не сохраняются,
  пункт меню на папках не убрать [R F12, F3].
- RegKeeper: тема (как в Windows, светлая, тёмная), пункт «Удалить с RegKeeper» для exe и ярлыков в HKCU,
  автозапуск слежения. Интерфейс только на русском.
- Состояния: запись в HKCU не удалась (галочка возвращается к фактическому состоянию).
