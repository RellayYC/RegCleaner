# План тестирования RegKeeper

Сценарии взяты из состояний в `replica/recon-map.md`. Пометки:
- [A] автотест в `tests/RegKeeper.Tests` (имя теста), гоняется `node scripts/gates/check.mjs tests` (G1);
- [Р] ручная проверка в запущенном приложении (G18), тестовые данные: `HKCU\Software\RegKeeperTest`,
  `%TEMP%\RegKeeperTest`.

Общие граничные случаи, которые касаются всех модулей:
- Нет прав администратора: приложение требует повышения (`requireAdministrator` в манифесте), без UAC не
  запускается. Код, который без прав работать не должен, проверяет их сам [A Replace_RefusesWithoutBackupOrAdmin].
- Защищённые ключи и папки: ни один модуль их не удаляет [A SystemKeys_AreRefused, SystemFolders_AreRefused,
  SharedVendorFolderNeverOffered].
- Длинные пути (> 260 символов): манифест `longPathAware`; снимок видит файл, корзина удаляет папку
  [A LongPath_SnapshotSeesTheFile, LongPath_RecycleRemovesTheFolder].
- Отмена посреди операции: прерванная транзакция видна в Центре отмены со своим составом и откатывается
  [A Undo_InterruptedTransaction_ListsItsItems]; прерванный снимок не оставляет файла
  [A Snapshot_Cancelled_LeavesNoFile]; Esc отменяет снимок, трассу и анализ очистки диска, ошибка не
  показывается [A Busy_EscCancelsWithoutError], [Р] Esc посреди снимка полной системы.
- Повторный откат: запись удаляется после отката, второй откат падает с ошибкой и ничего не меняет
  [A Undo_RestoringTwice_FailsCleanly].
- Нехватка места: бэкап пишется в undo.reg до изменения; если запись не удалась, изменение не выполняется
  (исключение из `File.AppendAllText` до `Reg.Write`/`DeleteTree`). [Р] не воспроизводится без заполнения диска,
  проверено чтением кода `UndoTx.Block`.
- Обе темы: каждый экран открывается в светлой и тёмной [A EveryView_OpensInBothThemes].

## Деинсталлятор
- [Р] Список грузится, окно заблокировано на время загрузки; поиск по названию фильтрует; пустой поиск -
  пустая таблица.
- [Р] «Удалить» у программы с рабочим деинсталлятором: после него окно хвостов с галочками, снятая галочка
  не удаляется.
- [Р] Программа без деинсталлятора: предлагается «Принудительно», процессы программы закрываются.
- [Р] «Убрать запись», затем откат в Центре отмены: запись возвращается.
- [Р] «Экспорт» в CSV, «Папка», «Ключ в редакторе» открывают нужное.
- [A] Хвосты: строгое совпадение папок, папка издателя только если она целиком принадлежит программе, общая
  папка издателя не предлагается [Folders_StrictMatch_AndVendorOnlyWhenExclusive, SharedVendorFolderNeverOffered].

## Приложения Windows
- [A] Список с реальной системы, фреймворки и системные пакеты отфильтрованы, имя пакета не попадает в текст
  скрипта [Load_DoesNotThrow, Parse_SingleObjectAndFiltering, Load_RealSystem_And_RemovalKeepsNameOutOfScript].
- [Р] «Показать системные» добавляет пакеты, у системных кнопка «Удалить» недоступна.
- [Р] Пакет, который не удаляется: ошибка PowerShell показывается пользователю.

## Автозагрузка
- [A] Run-запись: выкл, удаление, откат возвращают исходное состояние [RunEntry_DisableDeleteUndo_RoundTrips].
- [A] «Отложить»: запись переносится в задачу с задержкой, откат удаляет задачу и включает запись
  [Delay_MovesEntryToDelayedTask_AndUndoRemovesIt, SplitCommand_SeparatesProgramAndArgs].
- [Р] Фильтры «Службы» и «Задачи»; службы Microsoft не показываются.
- [Р] RunOnce: «Вкл / выкл» недоступно, удаление работает.
- [Р] Запись на несуществующий файл помечена «файл не найден»; [A] «не найден» только для абсолютных путей,
  не для `notepad.exe`, переменных и сетевых путей [IsMissing_OnlyForRootedAbsentFiles].
- [Р] «Добавить», «Папка файла», «Перейти к записи».
- [A] Слежение замечает новую запись Run и молчит о старых [DetectsNewRunEntry_IgnoresKnown].

## Очистка диска
- [A] Встроенные пункты и правила winapp2 анализируются, исключения и `RemoveSelf` соблюдаются
  [Analyze_Clean_RespectsPatternsExcludesAndRemoveSelf, ExpandVars_ProgramFilesMeansBoth].
- [A] Весь upstream winapp2.ini разбирается без ошибок [UpstreamFile_ParsesFully].
- [Р] Без базы winapp2 подсказка в строке состояния, «Обновить winapp2.ini» скачивает и перечитывает.
- [Р] «Подробно»: снятая галочка у файла - файл остаётся.
- [Р] Занятый файл (открыт в другой программе): очистка не падает, он попадает в «пропущено».
- [Р] Повторный анализ сразу после очистки: удалённое не находится снова.

## Чистка реестра
- [A] Битый «Открыть с помощью» находится, исправляется и откатывается [BrokenOpenWith_FoundFixedAndUndone].
- [Р] Скан по кнопке, у каждой находки колонка «Проблема».
- [Р] «Игнорировать» - находка не появляется при следующем скане; удаление из списка исключений возвращает её.
- [Р] «Исправить» только отмеченное; защищённый ключ в отчёте «не удалено».
- [Р] «Открыть» переходит к ключу в редакторе.

## Редактор реестра
- [A] .reg экспорт, импорт, экспорт байт в байт, все типы значений [RegFile_RoundTrip_IsExact,
  ParsesHexAndRejectsOverflow].
- [Р] Создать, переименовать, копировать, удалить раздел на `HKCU\Software\RegKeeperTest`; каждое действие
  в Центре отмены и откатывается.
- [Р] Копировать раздел в себя или в существующий - отказ с сообщением.
- [Р] Значения всех типов: создать, изменить, переименовать, удалить; неверный DWORD - повтор ввода.
- [Р] Экспорт `HKEY_CURRENT_USER` целиком: окно отвечает, курсор занятости.
- [Р] Импорт .reg: окно предпросмотра со списком операций, снятая галочка не применяется.
- [Р] Нет доступа к разделу (например `HKLM\SECURITY`): сообщение, без падения.
- [Р] Адресная строка, «Из буфера», «Копировать путь», избранное переживает перезапуск.

## Поиск и замена
- [A] Поиск, замена и откат замены [FindReplaceUndo].
- [Р] Остановка поиска кнопкой посреди обхода `HKLM`: найденное до остановки остаётся.
- [Р] Неверный regex: сообщение, поиск не запускается.
- [Р] Ничего не найдено: пустой список и статус.
- [Р] «Удалить» отмеченное, «Открыть» в редакторе.

## Снимки и трассы
- [A] Снимок, сравнение, откат трассы [TakeDiffRollback, PathOrder_IsSegmentWise].
- [Р] «Снимок» полной системы (~40 с), курсор занятости, файл появляется в списке.
- [Р] «Сравнить» два одинаковых снимка: изменений нет.
- [Р] «Трасса» установки небольшой программы, откат с галочками; изменённые файлы показаны списком.

## Твики
- [A] Каталог полный и корректный (G2); применение и откат на реальном реестре [ApplyRefreshUndo,
  ShippedCatalog_LoadsAndConverts].
- [Р] Галочка отражает текущее состояние; «Применить» одной записью в Центре отмены.
- [Р] Твик с «Нужно: Проводник»: вопрос о перезапуске Проводника.
- [Р] «Сбросить отметки», «Ключ в редакторе».

## Сжатие реестра
- [A] Планирует основные хайвы, без прав и без бэкапа отказывает [Plan_FindsMainHives,
  Replace_RefusesWithoutBackupOrAdmin].
- [Р] «Анализ» под администратором: размеры до и после, система не меняется.
- [Р] «Сжать» не проверяется на основной системе (замена хайвов при перезагрузке) - только на виртуальной
  машине перед релизом.

## Центр отмены
- [A] Откат всех видов изменений [Undo_RestoresEverything], прерванная транзакция и повторный откат (см. выше).
- [Р] Список, состав записи, «Отменить» несколько записей сразу (новые первыми), «Удалить», «Удалить старые»,
  «Открыть .reg».
- [Р] Повреждённый info.json: запись пропускается, остальные видны.

## Настройки
- [A] Пункт меню и автозапуск слежения регистрируются и снимаются в HKCU [ShellVerb_RegistersAndRemoves,
  WatcherAutostart_RegistersAndRemoves]; тема сохраняется [Theme_PersistsAndResolves].
- [Р] Переключение темы сразу перекрашивает открытый экран.
- [Р] Пункт «Удалить с RegKeeper» в меню exe открывает деинсталлятор на нужной программе.
