# RegKeeper

Деинсталлятор, автозагрузка, чистка диска и реестра для Windows 10/11, где каждое изменение можно откатить.
Ничего не висит в фоне, ничего не удаляется без списка с галочками и подтверждения.

## Возможности

- **Деинсталлятор** - все программы из Uninstall (HKLM, HKCU, WOW6432Node) с размером и датой, запуск штатного
  удаления, поиск хвостов (папки и ключи) после него, принудительное удаление битых записей.
- **Приложения Windows** - пакеты Microsoft Store; системные и фреймворки скрыты по умолчанию.
- **Автозагрузка** - Run/RunOnce, папки автозагрузки, задачи планировщика, сторонние службы. Включение и
  отключение без удаления, пометка записей с несуществующим файлом.
- **Очистка диска** - правила community-базы [winapp2](https://github.com/MoscaDotTo/Winapp2) (только для
  установленных программ, обновление одной кнопкой) плюс встроенные: Temp, кэш Windows Update, дампы, эскизы,
  корзина. Сначала анализ с размерами, потом удаление.
- **Чистка реестра** - битые пути в Uninstall, App Paths, SharedDLLs, MUICache, OpenWith, CLSID, TypeLib, Run.
  Список исключений.
- **Редактор реестра** - дерево, все типы значений, экспорт/импорт `.reg`, избранное, переход по адресу из буфера.
- **Поиск и замена** - по именам ключей, значений и данным, с regex, отменой посреди поиска и массовой заменой.
- **Снимки и трассы** - снимок реестра и файлов, сравнение двух снимков, трасса установки с откатом ровно того,
  что поставил инсталлятор.
- **Твики** - подборка известных настроек Windows с текущим состоянием, применение одной записью отмены.
- **Сжатие реестра** - анализ «до/после» и замена хайвов при перезагрузке.
- **Центр отмены** - журнал всех изменений, откат любого из них.
- **Настройки** - тема, пункт «Удалить с RegKeeper» в меню Проводника, фоновый сторож автозагрузки.

## Установка

Нужна Windows 10/11 x64. Скачайте `RegKeeper.exe` из релиза и запустите: установка не требуется, .NET встроен.
Программа просит права администратора, потому что пишет в HKLM и системные папки.

Сборка из исходников (.NET 8 SDK):

```
dotnet test RegKeeper.sln
dotnet publish src/RegKeeper/RegKeeper.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

Данные (Центр отмены, снимки, трассы, исключения, `winapp2.ini`) лежат в `%ProgramData%\RegKeeper`.
Чтобы удалить программу полностью, удалите exe и эту папку; если включали пункт в Проводнике или сторожа, сначала
выключите их в Настройках.

## Безопасность

- Перед любым изменением реестра ключ сохраняется в Центр отмены (`%ProgramData%\RegKeeper\Undo`), откат одной
  кнопкой. Хвосты деинсталлятора уходят в корзину.
- Системные ключи и папки (корни хайвов, `SAM`, `SECURITY`, `BCD`, `Windows`, `Program Files` и т.п.) в защищённом
  списке: ни один модуль не предлагает их к удалению.
- Сжатие реестра работает только с правами администратора, после точки восстановления и полной копии хайва;
  системные хайвы вроде SAM и SECURITY не трогает.
- Имена пакетов и пути не подставляются в строки команд PowerShell или cmd.
- Очистка диска удаляет файлы мимо корзины: это мусор. Смотрите «Подробно» перед удалением и добавляйте
  исключения.

Чистка реестра не ускоряет Windows заметно. Используйте её, чтобы убрать следы удалённых программ, и делайте это
осознанно: программа поставляется «как есть», без гарантий.
